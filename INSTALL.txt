Music DLP - Installation
========================

Music DLP downloads audio from YouTube playlists/videos, X/Twitter posts,
and other yt-dlp-supported links, then converts it to MP3 and M4A with
embedded album art.

It does not use AI and does not rename titles: files keep the original
source title, and the channel/uploader is embedded as the artist tag.


REQUIREMENTS
------------

1. Python 3.10 or newer (from https://www.python.org/downloads/)
2. FFmpeg
3. Optional: a cookies.txt file for protected or age-restricted posts


STEP 1: Install FFmpeg
----------------------

Option A - Put FFmpeg next to the app
  1. Download a Windows build from https://ffmpeg.org/download.html
     (the "release essentials" build is enough)
  2. Extract it
  3. Copy ffmpeg.exe and ffprobe.exe into one of these places:
       - The same folder as main.py / MusicDLP.exe
       - A folder named "ffmpeg" next to main.py / MusicDLP.exe

Option B - Install system-wide
  Install FFmpeg with winget:
      winget install Gyan.FFmpeg
  Then open a NEW terminal so PATH updates.

Verify it works:
      ffmpeg -version


STEP 2: Install Python dependencies
-----------------------------------

Open a terminal in the Music-DLP folder and run:

      pip install -r requirements.txt


STEP 3 (Optional): Cookies
--------------------------

Some YouTube videos and protected X/Twitter posts require you to be signed
in. To provide cookies:

  1. Install the browser extension "Get cookies.txt LOCALLY"
  2. Sign in to YouTube / X in that browser
  3. Export cookies to a file (cookies.txt)
  4. In Music DLP: Settings > Download > Cookies File > Browse
     and select the file


RUNNING FROM SOURCE
-------------------

      python main.py


BUILDING THE EXE
----------------

      pip install pyinstaller
      python build_exe.py --clean

Output: dist/MusicDLP/

Copy ffmpeg.exe and ffprobe.exe into dist/MusicDLP/ffmpeg/ before running.


USING THE APP
-------------

1. Paste one or more links into the Link(s) box and press Add.
   Supported examples:
     https://www.youtube.com/playlist?list=...
     https://www.youtube.com/watch?v=...
     https://youtu.be/...
     https://x.com/user/status/...
     https://twitter.com/user/status/...

   You can paste several links at once, one per line.

2. Select the songs you want (checkboxes, "Select All", or
   "Select Downloaded").

3. Click "1. Download".

4. Click "2. Convert" to create MP3 + M4A files.

Output folders:
      downloads/final/mp3/
      downloads/final/m4a/


TROUBLESHOOTING
---------------

- "FFmpeg not found":
  Put ffmpeg.exe next to main.py / MusicDLP.exe, or in a "ffmpeg"
  subfolder, or install it system-wide and reopen the terminal.

- Download fails with 403 / bot detection:
  Your cookies may be missing or expired. Re-export cookies.txt and
  select it in Settings.

- X/Twitter post fails:
  The post may be protected, deleted, or region-locked. Try a cookies
  file; if the post has no video, there is nothing to download.

- A download or conversion was interrupted:
  Just run it again. Music DLP resumes completed items automatically.

- Logs:
  See the logs/ folder for details.
