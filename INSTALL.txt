Music DLP - Installation
========================

Music DLP downloads audio from YouTube playlists and videos, X/Twitter posts,
and other yt-dlp-supported links. It converts the audio to tagged MP3 (and
optionally M4A) and can copy the results into your Spotify Local Files folder.

It keeps the original published titles. You can edit metadata per track.


REQUIREMENTS
------------

1. Windows 10 or 11
2. FFmpeg (required for conversion)
3. Optional: Spotify Desktop, for Local Files delivery
4. Python 3.10 or newer (only if running from source; the .exe includes it)


QUICK START (the .exe)
----------------------

1. Download MusicDLP-<version>.zip from the latest release page and unzip
   it anywhere you can write to (for example your user folder, not Program
   Files). It contains one MusicDLP folder.
2. Run MusicDLP.exe. If Windows SmartScreen warns, choose "More info" then
   "Run anyway" - the build is not code-signed.
3. The first-run wizard opens. Press "Install it for me" to get FFmpeg, or
   point it at an ffmpeg.exe you already have.
4. Leave the wizard's Spotify folder as it is, then follow its "Show me how"
   steps once: Spotify -> Settings -> Show local files -> Add a source ->
   choose the Music DLP Spotify folder.
5. Optional, inside Spotify: install Spicetify and Marketplace from
   https://spicetify.app, start Music DLP once and close it, then run
   .\spicetify\install-panel.ps1 from this folder. Start Spotify and open
   Music DLP in the left navigation bar.

Python is not needed for the .exe. The rest of this file explains the
source install and every step in more detail.


STEP 0: What the .exe needs
---------------------------

The folder contains Python and every library the app needs. FFmpeg is the
only outside helper: either let the first-run wizard install it, put
ffmpeg.exe in the "ffmpeg" folder beside MusicDLP.exe, or install it with
winget install Gyan.FFmpeg.

The rest of this file is for running from source or for a manual setup.


STEP 1: Install FFmpeg
----------------------

Option A - System-wide (recommended)

    winget install Gyan.FFmpeg

Then open a NEW terminal so PATH updates. Check it works:

    ffmpeg -version

Option B - Portable

  1. Download a Windows build from https://ffmpeg.org/download.html
  2. Copy ffmpeg.exe and ffprobe.exe into one of:
       - The same folder as main.py / MusicDLP.exe
       - A folder named "ffmpeg" next to it

Option C - Point the app at it

  Settings -> Advanced -> FFmpeg path -> Browse.


STEP 2: Install and run
-----------------------

From source:

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python main.py

Pre-built app:

    Extract the folder and run MusicDLP.exe


FIRST RUN
---------

"Set up Music DLP" walks through four pages:

  1. Install or locate FFmpeg ("Install it for me" can do it).
  2. Check that the Spotify desktop app is installed.
  3. Choose the folder Spotify will read songs from.
     Default: C:\Users\<you>\MusicDLP\Spotify
  4. Show that folder to Spotify once: Add a source -> Select Folder,
     then click "Restart Spotify".

Easy/Pro mode, the output folder, and cookies are changed later in
Settings; the wizard does not ask for them.

Cookies are only needed for age-restricted YouTube videos and protected
X/Twitter posts. The easiest option is "Use cookies from a browser"; choose
the browser you are signed in with. Chrome may need to be closed while its
cookie database is read. A cookies.txt file also works.


USING THE APP
-------------

1. Paste one or more links into the bar at the top and press Add.

   Examples:
     https://www.youtube.com/playlist?list=...
     https://www.youtube.com/watch?v=...
     https://youtu.be/...
     https://x.com/user/status/...

   You can paste several links at once (one per line), or drag links onto the
   window.

2. Select the tracks you want. Newly added tracks are selected for you.

3. Press the main button:
     Easy mode: "Download to Spotify"
     Pro mode:  Download, then Convert, then Spotify

Converted files:
     <output folder>\MP3
     <output folder>\M4A      (if enabled)

The default output folder is C:\Users\<you>\MusicDLP.

Files copied for Spotify:
     <Spotify folder>       (default: C:\Users\<you>\MusicDLP\Spotify)


GETTING TRACKS INTO SPOTIFY
---------------------------

Spotify does not let other apps upload local files or add them to playlists.
Music DLP writes tagged files into a folder and can restart Spotify so it
rescans. Do this once:

  1. Open Spotify Desktop.
  2. Click your profile picture -> Settings.
  3. Under Local Files, turn on "Show local files".
  4. Click "Add a source" and choose the Music DLP Spotify folder.
  5. Restart Spotify (Settings -> Spotify -> Restart Spotify now).

Your tracks then appear under Your Library -> Local Files. Drag them into a
playlist inside Spotify if you want one.


THE PANEL INSIDE SPOTIFY (optional)
-----------------------------------

Spotify will not let another program add local files to a playlist, but
Spicetify runs inside the client and can. The "spicetify" folder next to
this file holds the panel and its installer.

  1. Install Spicetify (https://spicetify.app) and Marketplace.
  2. Start Music DLP once, so it writes its settings, then close it.
  3. In PowerShell, from this folder:
       .\spicetify\install-panel.ps1
     The installer finds spicetify.exe on PATH or in the usual install
     folders. If it cannot find it, add the folder that holds spicetify.exe
     to PATH and run the script again.
  4. Start Spotify. "Music DLP" appears in the left navigation bar.

The installer closes Spotify while it applies the theme. The panel talks to
the running Music DLP over 127.0.0.1 only. Desktop changes appear in the
panel within a few seconds; a folder can also be synced from the desktop
with Edit -> Sync this folder to its Spotify playlist.


EDITING METADATA
----------------

Select a track to see the Details panel (it is visible in both modes):

  - Title, Artist, Album, Track number
  - Apply metadata saves the values
  - Re-convert writes them into the audio file (and renames it)

The filename template is in Settings -> Output. Default: {title}
Other placeholders: {artist} {album} {track} {id} {media_id} {source}

To change many songs at once: tick them, then Edit -> Edit details for
ticked songs. It can set an album, an artist, a run of track numbers, or
replace part of every title (plain text or a regular expression), and write
the result into the files immediately.

View -> Browse by artist and album groups the whole library and shows cover
thumbnails. View -> Saved filters stores the current status filter and
search text under a name.

If something does not work, Settings -> Advanced -> Run diagnostics checks
FFmpeg, yt-dlp, cookies, the folders, Spotify, the panel, the AI setup and
free space, and copies one report.


TROUBLESHOOTING
---------------

"FFmpeg not found"
  Install with winget, place ffmpeg.exe next to the app, or set the path in
  Settings -> Advanced. Downloads still work without it; conversion does not.

YouTube sign-in check / 403
  Settings -> Download -> Cookies -> choose your browser. Retry the track.

X/Twitter post fails
  The post may be protected, deleted, region-locked, or contain no video.
  Try browser cookies.

Nothing appears in Spotify
  Check that the folder is added under Settings -> Show local files, and
  restart Spotify. Rescanning can take a minute for large libraries.

Duplicate tracks in Spotify
  Send only MP3 to Spotify (Settings -> Spotify -> Format sent to Spotify).

A job seems stuck
  Press Cancel in the status bar. Interrupted items resume next time.

Logs
  %LOCALAPPDATA%\MusicDLP\logs\musicdlp.log
  Or use the Logs button in the app and "Open log file".


IMPORTING AN OLD LIBRARY
------------------------

File -> Import old library, or accept the prompt on first launch if a
music_dlp.db from the previous version is found. Existing files are
referenced in place; nothing is moved or deleted.
